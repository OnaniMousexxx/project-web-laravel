Project web Laravel — S1 Sistem Informasi, Universitas Pamulang.

> Repo ini masih kosong. Isi awal Laravel belum di-push.

## Rencana isi

- Aplikasi web Laravel (tambahkan `composer create-project laravel/laravel` atau push project lokal lo ke sini)
- Setup standar Laravel: `composer install`, copy `.env.example` ke `.env`, `php artisan key:generate`, `php artisan migrate`, `php artisan serve`
